## Projects

| Project | What it does |
| --- | --- |
| [Dice](https://github.com/cozycommons/cc/blob/main/docs/dice-feature-map.md) | Live scoring, tournaments, player ratings, and predictions. |
| [Crowdset](https://github.com/cozycommons/cc/blob/main/docs/crowdset/README.md) | Combine friends’ concert recordings into synchronized video and audio mixes. |
| [Cozy Trips](https://github.com/cozycommons/cc/blob/main/docs/cozy-trips.md) | Shared trip expenses, balances, and repayments. |
| [Beli](https://github.com/cozycommons/cc/blob/main/docs/beli.md) | Restaurant recommendations and bookmarks, including finds from Instagram. |
| [Partiful](https://github.com/cozycommons/cc/blob/main/docs/partiful.md) | Access to friends’ hosted, RSVP’d, and invited events. |
| [Resy](https://github.com/cozycommons/cc/tree/main/backend/resy) | Restaurant search, availability, and reservations. |
| [ESPN Fantasy](https://github.com/cozycommons/cc/tree/main/backend/espn) | League stats, rosters, and opt-in lineup automation. |

All projects live in the [cc monorepo](https://github.com/cozycommons/cc).
